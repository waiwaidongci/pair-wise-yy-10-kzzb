# zfl-42 小型漆线雕工坊管理

独立静态前端应用，直接打开 `index.html` 即可使用（双击或 `python3 -m http.server` 均可）。
数据保存在浏览器 localStorage，支持 JSON 导出。

## 三层分离

| 文件 | 职责 |
| --- | --- |
| `js/store.js` | **作品数据层**：作品与验稿单的存取、localStorage 持久化、旧版数据迁移。不含规则、不碰页面。 |
| `js/inspection.js` | **验稿判定层**：全部业务规则（能否签收、作废重排、复检判定），纯函数式调用，不碰 DOM。 |
| `js/app.js` | **页面操作层**：看板渲染、筛选、表单与弹窗交互；判定一律调用 `Inspection`。 |

## 验稿规则

- **一作品一单**：每件作品至多有一张「未结束」（非已作废）的验稿单；开单必须登记客户姓名与到店时间。
- **签收判定**：贴线进度满（100%）且无断线 / 翘线才可签收；不满足则停在「待修整」，修整后可复检，通过后回到「待验」。
- **自动作废重排**：签字之后若更换胎体、纹样或线条，或补记断线 / 翘线，原确认自动作废，并以原客户重新排队生成新验稿单（到店时间需重新登记）；旧单与旧签字人、签字时间保留在验稿履历和作品履历中。
- **看板筛选**：验稿看板筛出「待验 / 待修整 / 已确认」三类（全部视图另列「未排验」）；工序看板维持贴线中、待阴干、上金粉、待交付四列，并显示每件作品当前验稿状态。

## 既有功能

- 新增作品并记录胎体、纹样、线条、贴线进度、阴干日期、金粉状态、缺陷和交付日期。
- 今日到店验稿、缺陷作品、最近交付三类摘要。
- 工序状态流转、缺陷记录与修整复检、作品详情与完整履历。
- 主题 / 状态筛选、日期排序、localStorage 持久化和 JSON 导出。
